Review a browser journey for each criterion

Write one action per line. Quote visible labels and text. Every criterion needs at least one expect assertion. Review that the assertions actually establish its expected outcome.

Supported actions and example
open /
fill "Item name" "Example item"
click button "Add item"
expect text "Example item"

Use click button "Name" or click link "Name" for accessible controls. expect heading "Name" checks a visible element. Supported roles: button, link, heading, textbox, checkbox, radio, tab, status.

For elements with a test ID, use click testid "add", expect testid "result", or expect testid "result" "Exact text". fill "Field label" "Value" uses a field’s label. Text and names match exactly.

Upload the built-in 96px PNG circle with upload label "Photo" png-circle-v1 or upload testid "photo-input" png-circle-v1. The target must be a file input. Fixtures are fixed synthetic images; host paths and external URLs are not accepted.

Click a download control and verify the returned file with download button "Download SVG" svg-v1. Link and testid targets also work. The check requires UTF-8 SVG with a nonempty viewBox, vector elements, and a supported passive structure, at most 16 MiB. Active content and external resources are rejected. It records file identity and structure, not visual quality or whether the artwork matches the photo. Downloaded bytes are deleted after checking.

For styled controls, click text "Visible label" clicks their visible text. press slider "Detail" Home adjusts an enabled slider using its keyboard control. Supported keys: Home, End, ArrowLeft, ArrowRight, ArrowUp, ArrowDown. Follow interactions with assertions that verify their outcome.

Plans using uploads, downloads, text clicks, or slider keys use version 2, allowing up to 45 seconds for a browser action while the whole run stays limited to two minutes. Existing version 1 plans retain their original timeouts. External APIs, performance, and arbitrary scripts remain unsupported. Keep unsupported requirements explicitly outstanding; do not replace them with an unrelated text assertion.
